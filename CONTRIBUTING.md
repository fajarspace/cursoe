# Contributing

Thanks for your interest in Cursoe. Bug reports, ideas and pull requests are all welcome.

## Reporting bugs

Open an issue and include:
- your Mac model and macOS version, and your Android device and Android version;
- how the devices are connected (USB tethering, USB debugging, hotspot or Wi-Fi);
- what you did, what you expected, and what happened;
- logs if possible: `log stream --info --predicate 'subsystem == "dev.cursoe.mac"'` on the Mac and
  `adb logcat -s Cursoe CursoeDbg` on Android.

## Pull requests

1. Set up the toolchain and build both apps as described in [docs/development.md](docs/development.md).
2. Keep changes focused; one topic per pull request.
3. Test on a real Mac and Android device. Most of Cursoe (input capture, accessibility gestures, input methods)
   cannot be exercised in a simulator.
4. Do not add third-party dependencies to the Mac or Android apps without discussing it in an issue first. Both apps
   intentionally use only platform APIs.
5. Never commit screen recordings, logs or screenshots that contain personal data.

## Conventions

- Mac: Swift, AppKit, Swift Package Manager. Android: Kotlin, Gradle wrapper.
- The apps are bilingual: English (default) and Indonesian. Every user-facing string needs both languages:
  `L("English", "Indonesia")` on the Mac, `tr("English", "Indonesia")` in Android code, and `values/strings.xml` +
  `values-in/strings.xml` for Android resources.
- Many code comments are in Indonesian. New comments may be in English or Indonesian.
- Brand assets (logo and icons) are generated by `scripts/brand/make-logo.py`; edit the generator, not the outputs.
